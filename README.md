# CKP CMP Simulator และสถานะงาน

อัปเดตสถานะวันที่ 11 ตุลาคม 2569

เอกสารนี้สรุปตำแหน่งไฟล์ Simulator และงานที่ต้องดำเนินการต่อ ตามข้อมูลล่าสุดจากผู้ปฏิบัติงาน สถานะที่ระบุไม่ใช่ผลทดสอบฮาร์ดแวร์ครั้งใหม่

## Simulator 3 รุ่นและตำแหน่งไฟล์

| รุ่น | ลักษณะ | โฟลเดอร์ | สถานะ |
| --- | --- | --- | --- |
| 1 | ปุ่มกด | [RP2040_3V3](RP2040_3V3/) | สร้างสัญญาณ CKP/CMP ได้ เอาต์พุต 3.3 V ยังต้องยืนยันการใช้งานร่วมกับ ECU |
| 2 | หน้าจอสัมผัส 1.8 นิ้ว | [CKP_CMP_RP2040_ZERO_V9](CKP_CMP_RP2040_ZERO_V9/) | สร้างสัญญาณและใช้หน้าจอได้ เอาต์พุต 3.3 V ยังต้องยืนยันการใช้งานร่วมกับ ECU |
| 3 | หน้าจอสัมผัส 2.8 นิ้ว | [SimulatorCMP,CKP V16ล่าสุด](SimulatorCMP%2CCKP%20V16ล่าสุด/) | กำลังพัฒนา วงจรปรับระดับสัญญาณยังใช้งานร่วมกันไม่ได้ และหน้าจอทำงานไม่สม่ำเสมอ |

เลขรุ่น 1–3 เป็นการแบ่งตามรูปแบบชิ้นงาน ส่วน V9/V16 ในชื่อโฟลเดอร์เป็นชื่อชุดไฟล์ที่ใช้ระบุตำแหน่ง ไม่ใช่จำนวนรุ่นชิ้นงานทั้งหมด

## วงจร EasyEDA ที่อัปโหลดแล้ว

ไฟล์วงจร EasyEDA เพิ่มไว้บน GitHub แล้วในโฟลเดอร์ [วงจรบนโปรแกรมEasyEDA](วงจรบนโปรแกรมEasyEDA/) โดยแยกเป็น [ไฟล์ PDF](วงจรบนโปรแกรมEasyEDA/PDF/) และ [ไฟล์ JSON สำหรับ EasyEDA](วงจรบนโปรแกรมEasyEDA/โค้ดเขียนวงจรสำหรับEasyEDA/) เพื่อให้ผู้ดำเนินงานต่อดาวน์โหลดไปตรวจสอบและใช้งาน

ตรวจพบ PDF 3 ไฟล์และ JSON 5 ไฟล์ ณ วันที่อัปเดตนี้ จำนวนไฟล์ไม่ใช่การนับจำนวนผลงานย้อนหลัง ซึ่งผู้ปฏิบัติงานแจ้งว่าเขียนวงจร 4 วงจรในช่วง 29 กันยายน–1 ตุลาคม 2569

รายละเอียดผลที่ทำได้ ข้อจำกัด และแนวทางดำเนินงานต่อให้ดูในสรุปสถานะก่อนเลือกชุดไฟล์ไปใช้ ชื่อไฟล์ที่มีคำว่า FINAL หรือ FIX ไม่ใช่หลักฐานว่าชิ้นงานผ่านการตรวจรับครบทุกด้าน

## การสำรองไฟล์

ให้สำรองข้อมูลที่จำเป็นไว้ในพื้นที่ที่สถานประกอบการควบคุมเองภายใน 10 วันปฏิทิน โดยเริ่มนับวันถัดจากวันส่งมอบจริงพร้อมสิทธิ์เข้าถึงที่ใช้งานได้ และยืนยันการสำรองเป็นลายลักษณ์อักษร หากส่งมอบวันที่ 20 ตุลาคม 2569 จะครบกำหนดวันที่ 30 ตุลาคม 2569

ผู้จัดทำมีแผนลบสำเนางานในพื้นที่ส่วนตัวรวมถึง repository นี้หลังครบกำหนดและได้รับคำยืนยันการสำรองข้อมูลแล้ว หากยังเข้าถึงไม่ได้หรือไฟล์ไม่ครบ ให้แจ้งผ่านช่องทางงานก่อนครบกำหนด การอัปเดต README นี้ไม่ถือเป็นหลักฐานว่ามีการส่งมอบหรือสำรองครบแล้ว
